How this is built

  • No build step and no framework. It is plain HTML, CSS and JavaScript, served as is by GitHub Pages.
  • The home page weighs about 58 KB before compression (HTML, CSS, JavaScript and JSON), plus two Google fonts.
  • Projects live in one data file, data/projects.js. Adding an entry adds a slide, an envelope and a letter.
  • The heavier effects are optional. Falling leaves and the brush trail are off by default and can be switched on in Settings. Touch devices, low-core machines and Save-Data mode also skip the ink filters and birds. Reduced motion turns off animation everywhere.
  • A nightly GitHub Action writes my latest commits to a data file for the “Currently building” strip.
  • Playwright runs on every push, taking light and dark screenshots and checking that nothing overflows on a phone.
